## المميزات

- **المواد** بألوان ودرجات، ولوحة رئيسية تعرض المواعيد القادمة والمهام المفتوحة.
- **المستندات**: استيراد ملفات PDF أو مسح الورق بالكاميرا مع فلاتر وحفظه بصيغة PDF. الصفحات الممسوحة قابلة للبحث بفضل التعرف على النص داخل الجهاز.
- **التسجيلات**: تسجيل المحاضرات مع إيقاف مؤقت وعلامات وتسجيل في الخلفية. التشغيل يدعم تغيير السرعة ويتذكر آخر موضع.
- **الملاحظات**: نصوص وعناوين وقوائم وقوائم مهام وجداول ورسوم بيانية وصور ورسم بقلم Apple Pencil، على ورق فارغ أو مسطّر أو مربعات.
- **المهام والمواعيد** مع تذكيرات محلية.
- **البحث** في العناوين ونصوص الملاحظات ونصوص ملفات PDF.
- **نسخ احتياطي واسترجاع** بملف ZIP واحد.
- **عربي وإنجليزي** مع دعم كامل للكتابة من اليمين لليسار.
- **خصوصية كاملة**: كل شيء يُحفظ على جهازك، بدون حسابات وبدون خوادم.

## المتطلبات

- آيفون بنظام iOS 16.0 أو أحدث (بالوضع الطولي).
- للبناء: جهاز Mac فيه Xcode، أو الـ workflow الموجود في المشروع.

## البناء

مشروع Xcode يُولَّد من `project.yml` بأداة [XcodeGen](https://github.com/yonaskolb/XcodeGen)، والاعتماد الوحيد هو [ZIPFoundation](https://github.com/weichsel/ZIPFoundation).

```bash
brew install xcodegen
xcodegen generate
open Studix.xcodeproj
```

### بدون Mac

الملف `.github/workflows/build.yml` يبني التطبيق على جهاز macOS تابع لـ GitHub:

1. ارفع التعديلات إلى `main`، أو افتح **Actions ← Build and Validate Studix ← Run workflow**.
2. عند نجاح التشغيل، تجد الملف `Studix-unsigned.ipa` في إصدار **latest**.
3. إذا فشل البناء، حمّل ملف `build-log` من صفحة التشغيل.

## التثبيت

ملف IPA **غير موقّع**. وقّعه وثبّته بأداة تثبيت جانبي مثل AltStore أو SideStore أو Sideloadly. التطبيقات الموقّعة بحساب Apple مجاني تنتهي بعد 7 أيام وتحتاج توقيعاً جديداً.

## هيكل المشروع

```text
Sources/
  StudixApp.swift       نقطة البداية والثيم والتبويبات
  DesignSystem.swift    المكونات المشتركة والواجهة الرئيسية
  Models.swift          النماذج والتخزين المحلي والنسخ الاحتياطي
  Library.swift         المواد وقوائم المحتوى
  Documents.swift       قارئ PDF وربط الماسح
  Scan.swift            تحرير المسح ومعالجة الصور
  Audio.swift           التسجيل والتشغيل
  Notes.swift           الملاحظات والرسم والجداول والرسوم البيانية
  Tasks.swift           قائمة المهام
  Deadlines.swift       المواعيد والتذكيرات
  Search.swift          البحث والتعرف على النص
  Settings.swift        اللغة والإحصائيات والنسخ الاحتياطي
  en.lproj/             النصوص الإنجليزية
  Assets.xcassets/      الأيقونة والصور
```

التفاصيل الهندسية في [ARCHITECTURE.md](ARCHITECTURE.md).

## بياناتك

يحفظ التطبيق مكتبتك في `Documents/Data`: ملف `index.json` للبيانات الوصفية، إضافة إلى ملفات PDF والصوت والملاحظات والرسومات ومجلد `Text/` لنصوص البحث. النسخة الاحتياطية هي ملف ZIP لهذا المجلد. الاسترجاع يتحقق من الأرشيف قبل استبدال أي شيء، ويحتفظ بالبيانات القديمة حتى تكتمل الجديدة.

## الترجمة

النصوص العربية هي المفاتيح الأصلية. أضف الترجمة الإنجليزية لكل نص جديد في `Sources/en.lproj/Localizable.strings`، وجرّب الواجهة بالاتجاهين.

## المساهمة

1. ضع كل ميزة في ملفات مستقلة، وأعد استخدام مكونات `DesignSystem.swift`.
2. حافظ على قراءة النسخ الاحتياطية القديمة، أو أضف ترحيلاً لها.
3. تعامل مع أخطاء الملفات والصوت والإشعارات بوضوح.
4. جرّب حالات الفراغ والخطأ والبيانات الكبيرة.
5. تأكد أن بناء GitHub Actions ينجح قبل الدمج.

سجل التغييرات في [CHANGELOG.md](CHANGELOG.md).
